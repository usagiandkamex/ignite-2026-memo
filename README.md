# Microsoft Ignite 2026 / Infra field notes

Microsoft Ignite 2026の公開セッションを、Infra・AIOps・SREの観点で整理する非公式の参加案です。Microsoftの公式見解・公式スケジュールではありません。

## サイト

GitHub Pagesで`main`ブランチの`docs`ディレクトリを公開します。スマートフォン向けの日別時間軸カレンダー、4日間比較、比較候補・分野フィルター、時間重複の横並び表示に対応します。

カードから会場、日本時間、重複相手、公式ページを確認できます。カードの高さは所要時間に比例します。短いセッションの詳細はタップして確認してください。

## 情報の扱い

- 公開するのは公式公開セッションの日時・会場・リンクと、公開内容に基づく短い要約・編集上の参加案のみです。
- 社内文書・社内URL・顧客情報・同行者との相談・個人の認証情報・予約状態・アカウント画面・提供資料の原本はコミットしません。非公開メモはリポジトリ外で管理します。`docs`以外もpublicリポジトリでは公開されます。
- `docs/sessions.json`の52件は2026/11/15に公式公開ページと照合しました。時刻はPST（UTC−8）で、日本時間は＋17時間です。`priority`は公開用の参加案であり、実際の登録・予約を示しません。
- 公式サイトの予定やFavoriteを変更する機能はありません。会場・時刻・参加条件は公式情報で最終確認してください。
- 解析・トラッキング、外部ライブラリ、外部フォント、認証連携は使用しません。

## 更新と確認

`docs/sessions.json`を編集し、各カードの公式URLで日付・時刻・会場を照合してください。`checked`に確認日、`note`に公開情報だけに基づく選定理由を記入します。公式説明文の全文転載は避け、短い要約にします。

```powershell
node --test
python -m http.server 8000 --directory docs
```

ローカル表示は`http://localhost:8000`です。`main`への反映後、GitHub Pagesが更新されます。最初の公開にはリポジトリ管理者がSettings → Pagesで`Deploy from a branch`、`main`、`/docs`を設定する必要があります。
