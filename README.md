# Microsoft Ignite 2026 / Infra field notes

Microsoft Ignite 2026の公開セッションを、Infra・AIOps・SREの観点で整理する非公式の参加案です。Microsoftの公式見解・公式スケジュールではありません。

## サイト

[公開カレンダーを開く](https://usagiandkamex.github.io/ignite-2026-memo/)

GitHub Pagesで`main`ブランチの`docs`ディレクトリを公開します。スマートフォン向けの日別時間軸カレンダー、4日間比較、比較候補・分野フィルター、時間重複の横並び表示に対応します。

カードから会場、日本時間、重複相手、公式ページを確認できます。カードの高さは所要時間に比例します。短いセッションの詳細はタップして確認してください。

候補を表示すると、重なるグループでは予定表に表示されていた枠が候補の左側に並びます。候補が多く重なる日は、カードを読める幅に保つため、日別表示でも時間表を横スクロールできます。

カードの左辺は、11/24に予定表で確認した枠が実線、未追加の比較候補が破線です。重複と会場間移動の詳細は時間表の下に表示します。登録状態は自動同期されません。

時間表の下では予定セッション間の15分以上の間隔を確認できます。移動・食事・共通プログラム・その他の予定は考慮しません。

「必ず参加」は参加案のメモであり、公式サイトの登録や座席確保を変更するものではありません。

別ページの[会場マップ](https://usagiandkamex.github.io/ignite-2026-memo/map.html)には主要会場・周辺施設・道路・駅の簡略地図と、Ignite公式インタラクティブMapや会場公式フロア図へのリンクがあります。地図は入口や徒歩経路を示しません。

[Azure インフラ](https://usagiandkamex.github.io/ignite-2026-memo/infra.html)では、Ignite 2026 の主なアップデートを分野別に読み、発表時点の提供状況、活用場面、導入前の確認事項を公式出典とともに確認できます。参加案とは独立したセッション一覧から、コンピューティング・ネットワーク・ストレージ・移行・運用と、App Service、Functions、Container Apps、AKS などの実行基盤も探せます。

[新発表ページ](https://usagiandkamex.github.io/ignite-2026-memo/updates.html)では、代表的な発表を図や仕事別の具体例で把握し、個別の解説やMicrosoft公式の図・画面へ進めます。Book of News全59発表と、基調講演・製品公式ブログなどで確認した補足について、機能ごとの変更点・メリット・発表時点の提供状態を掲載します。キーワード、分野、提供状態、出典区分で絞り込めます。

## 情報の扱い

- 公開するのは公式公開セッションの日時・会場・リンクと、公開発表やセッションに基づく短い要約・編集上の参加案のみです。
- 社内文書・社内URL・顧客情報・同行者との相談・個人の認証情報・予約状態・アカウント画面・提供資料の原本はコミットしません。非公開メモはリポジトリ外で管理します。`docs`以外もpublicリポジトリでは公開されます。
- `docs/sessions.json`のセッションは公式公開ページと照合しています。時刻はPST（UTC−8）で、日本時間は＋17時間です。`priority`は11/24に確認した予定表に基づく表示区分であり、最新状態や座席確保を示しません。
- 比較候補の`availability`は`add`が予定に追加できる表示、`standby`が満席・待機のみ、`unknown`が未確認です。`availabilityChecked`に記録した確認時刻は日本時間で表示し、最新の残席や座席確保を保証しません。
- 公式サイトの予定やFavoriteを変更する機能はありません。会場・時刻・参加条件は公式情報で最終確認してください。
- 自サイトには解析・トラッキング、外部ライブラリ、外部フォント、認証連携は使用しません。会場マップの位置データはOpenStreetMapに帰属表示しています。公式Mapは埋め込み制限があるためリンクとして提供します。
- `youtubeUrl`はMicrosoft Events公式YouTubeチャンネルの公開録画を11/24に照合し、公式セッションのタイトル・コードおよび動画の開催年を確認して追加したものです。▶の付いたカードの詳細から視聴できます。リンクのないセッションは、録画が存在しないことを意味しません。

## 更新と確認

`docs/sessions.json`を編集し、各カードの公式URLで日付・時刻・会場を照合してください。`checked`に確認日、`note`に公開情報だけに基づく選定理由を記入します。公式説明文の全文転載は避け、短い要約にします。

インフラ一覧は `docs/infra-sessions.json` を更新します。[公式公開カタログ](https://ignite.microsoft.com/en-US/sessions)のタイトル・概要・トピック・タグを照合し、同一セッションの開催枠はまとめます。DB・AI はインフラの設計や運用が主題の場合だけ掲載します。出典の確認日とカタログ全体の件数を記録し、公式のセッションコード・詳細ページ ID に独自の短い日本語要約を添えます。参加ステータスは記録しません。

インフラのアップデートは `docs/infra-updates.json` で管理します。`checked` は公式資料の確認日、`groups` のキーはセッション一覧と同じ分野 ID、`sessions` は一覧の関連セッションコードです。`status` は掲載した機能の発表時点の提供状況とし、製品本体との違いや公式資料間の不一致は `check` で説明します。`sources` には公式発表・製品文書を記録し、活用場面や検証手順は編集上の提案として区別します。

YouTubeの録画を追加する際は、同じセッションコードが別年にも存在するため、公式ページのタイトル・動画の開催年・Microsoft Eventsのチャンネルを確認し、`youtubeUrl`に動画URLを設定します。

Book of Newsの発表は`docs/updates-editorial.json`で独自の日本語要約を、`docs/updates-sources.json`で分野・公式アンカー・追加の公式出典を管理します。Bookにない発表や製品別発表の補足は`docs/updates-additional.json`に、安定した英小文字のスラッグとタイトル・分野・公式出典を記録します。どちらも`items`は`[提供状態, 変更点, メリット]`です。資料間の記載差は本文で説明して両方にリンクします。調査対象の媒体・期間は`docs/updates.html`に記載し、最新の提供地域、料金、ライセンス条件は推測しません。
